STICKFIGHTER — WEBSITE HOSTING FILES

This folder is the browser build of StickFighter. The main page is index.html.

IMPORTANT:
- Do not open index.html directly from the Chromebook Files app. This game uses JavaScript modules, workers, and other files that require an HTTP(S) web server.
- A school Chromebook with Linux disabled cannot run the local server instructions in README.txt.
- Google Sites is not a general-purpose static web host for uploading and running an entire game folder.

TO PLAY ONLINE:
1. Ask your teacher or school IT administrator which static website hosting service is approved for student projects.
2. Ask them to publish the CONTENTS of this folder as a static website, keeping the folder structure unchanged.
3. Open the HTTPS website address they provide in Chrome.

If the school does not allow student-hosted websites, ask whether they can provide an approved place to host or run this project. Do not try to bypass school web or device restrictions.
