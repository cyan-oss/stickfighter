STICKFIGHTER — BROWSER EDITION

The game files are included in this folder. The original Windows launcher is not needed.

IMPORTANT: Because this game uses JavaScript modules and worker files, opening index.html directly (file://) may be blocked by your browser. Run it from a small local web server instead.

EASIEST OPTION (Windows):
1. Install Python 3 if it is not already installed.
2. Double-click start_game_windows.bat.
3. Open the address shown (usually http://localhost:8000) in your browser.
4. To play in another tab, duplicate that tab or open the same address in a new tab.

CHROMEBOOK / MAC / LINUX:
1. Open a terminal in this folder.
2. Run: python3 -m http.server 8000
3. Open http://localhost:8000 in Chrome or another browser.
4. To play in another tab, open the same address in a new tab.

Keep the server/terminal window running while you play. Press Ctrl+C in the terminal to stop it.

The external Poki SDK and GameAnalytics script references were removed; the included game assets and Construct runtime are retained.
